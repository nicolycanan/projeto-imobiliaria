# Projeto: Orçamento Imobiliária 

## 📌 Objetivo
Sistema para calcular orçamento de aluguel com base em regras de negócio:
- Tipos de imóvel: Apartamento, Casa, Estúdio
- Regras para quartos, garagem, vagas extras e desconto
- Geração de parcelas do contrato e aluguel mensal
- Exportação para arquivo CSV
